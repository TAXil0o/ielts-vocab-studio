LEX 07.5 / IELTS VOCABULARY STUDIO
English Project Guide

1. OVERVIEW

LEX 07.5 is a browser-based IELTS learning workspace built around a simple
weekly vocabulary routine: study 100 lexical items a day for four days, then use
the next three days for spaced review. It also unifies listening, speaking,
reading and review activity in a daily mission dashboard.

The site contains two connected study layers:

1. The Round 1 plan: 400 daily-life words organized across four learning days.
2. The IELTS Word Bank: approximately 4,810 IELTS-tagged entries that can be
   filtered by theme and added to a personal study plan.

2. FEATURES

- Daily 100-word study dashboard with a progress ring and session checklist
- A daily mission dashboard ordered by the current IELTS preparation stage
- An Anime.js motion layer for view entrances, counting metrics, staggered resource
  cards and chart drawing
- AutoAnimate transitions for task, history, resource, question and review lists
- Morphdom local DOM patching to reduce full-container redraws and preserve focus
- Web Vitals monitoring for LCP, INP, CLS, FCP and TTFB
- Lazy loading for the large word-bank and synonym datasets; the home screen no
  longer downloads roughly 2.3 MB of unused JSON/JS before first interaction
- A settings screen with Full, Reduced and Off motion levels, plus a one-click
  option to follow the operating-system preference again
- Full mode adds button ripples, pointer-follow card glows, animated ambient
  shapes and a smoothly animated daily progress ring
- A separate open-resource library for official free links, CC BY textbooks,
  public-domain texts and audio, open data, and sentence corpora, with licence
  filters, favourites, and JSON catalogue import/export
- A unified activity timeline for vocabulary review, listening, speaking and reading
- Automatic stage, week and next-checkpoint display from the dated study plan
- Flip cards with a fixed British-English voice
- Chinese and English definitions for every entry, shown in cards, tables, and the word bank
- A paraphrase and synonym memory section with question wording, passage wording,
  English definitions, original sentences, and rewritten sentences
- Independent mastery and review status for each synonym family
- Completion status, mastery level, and personal notes
- Word filtering by learning day, tier, theme, pack, and status
- Three-day review cycle: listening recognition, spelling, and written output
- A timed reading laboratory with 13 questions, evidence notes, automatic scoring,
  three error categories, a paraphrase table, and saved review metadata
- A writing laboratory with six Academic Task 1 chart types, Task 2 opinion prompts,
  20/40-minute timers, word counts, outlines, four-criterion self-review, issue tags,
  three prioritised edits, and side-by-side revision tracking
- A full mock and progress centre with computer/paper modes, Listening 30 + Reading 60
  + Writing 60 + Speaking 15 minutes, four skill scores, overall practice Band,
  mock history, and the six plan checkpoints
- Weekly training-time trends across speaking, listening, reading, writing and vocabulary
- A sprint mode that reduces the home dashboard to speaking, listening retests,
  due vocabulary and writing review
- Four contextual reading passages with highlighted target words and cloze tests
- A listening laboratory that imports local audio plus SRT/VTT/TXT, supports
  segment playback, slow replay, looping, word-level dictation diffs, A–D error
  tagging, 48-hour retest scheduling, and local listening history
- A speaking studio with four 25–30 second micro-dialogues and connected-speech coaching
- Three switchable complete speaking mocks with Part 1 questions, a one-minute
  Part 2 preparation timer, a two-minute talk, Part 3 discussion questions,
  section recordings, and one selected improvement focus for the next attempt
- Microphone recording, instant replay, browser word-gap checks, and local attempt history
- One-click transfer of missed speaking words into the existing three-day vocabulary review
- Selectable themed word packs with automatic duplicate removal
- Selected words automatically split into 100-word training days
- A home and sidebar plan switcher for the Round 1 plan and the custom plan
- Separate progress records for the Round 1 and custom plans
- Legacy module state remains compatible with localStorage; unified activity is stored in IndexedDB
- JSON progress backup and restore
- CSV vocabulary export
- Responsive desktop and mobile layouts

Animation follows `prefers-reduced-motion` by default and can be adjusted from
Settings. All third-party frontend libraries are vendored locally with their
licenses under `vendor/`.

The listening laboratory is bring-your-own-material. It includes only an
original demo transcript, not commercial exam audio or subtitles. Imported audio
is read inside the current browser tab and is not uploaded; it must be selected
again after a refresh. Dictation results, error tags, and retest dates remain on
the local device.

Existing listening, speaking and vocabulary-review records are migrated into the
unified activity store on the first upgrade.

3. WORD BANK CATEGORIES

- High-frequency core
- Daily life
- Social interaction
- Work and career
- Education and learning
- Health and medicine
- Travel and transport
- City and environment
- Technology and media
- Consumer economy
- Social issues
- Academic language
- General vocabulary

Each entry receives a primary theme based on its Chinese meaning, English
definition, and topic keywords. A word may relate to more than one theme, but
it is placed in the best-matching pack for planning. The full bank remains
searchable.

4. FIXED PRONUNCIATION

The Round 1 plan and the IELTS Word Bank use MP3 files hosted with the website.
The fixed voice is:

en-GB-RyanNeural

This means desktop browsers, phones, and other visitors hear the same British
English pronunciation instead of the different system voices installed on each
device. Browser speech synthesis is used only as a fallback when an audio file
cannot be loaded.

5. DATA SOURCE AND LICENSE

The IELTS Word Bank is based on the public ECDICT dataset:

Project: https://github.com/skywind3000/ECDICT
License: MIT License

ECDICT provides the English headwords, phonetic transcriptions, Chinese
definitions, parts of speech, and IELTS tags. The Round 1 word list, theme
classification, learning workflow, passages, audio packaging, and interface
were prepared specifically for this project.

The synonym families use Open English WordNet 2025:

Project: https://github.com/globalwordnet/english-wordnet
License: CC BY 4.0, with the underlying Princeton WordNet license notices.

Exam-oriented paraphrase families and example sentences were prepared for this
project.

6. PRIVACY AND LOCAL STORAGE

- There is no account or server-side learner database.
- Completion status, mastery levels, and review scores stay in the visitor's
  own browser localStorage.
- Speaking audio is not written to localStorage and is not uploaded to this
  website's own server.
- Browser speech recognition may process audio through the browser or platform
  provider. An optional phoneme analyzer receives audio only when configured.
- Speaking duration, transcript and score summaries are stored with local progress.
- Clearing browser site data removes the progress stored on that device.
- Visitors should export a JSON progress backup regularly.
- Sharing the website URL does not share anyone's learning progress.

7. RUNNING LOCALLY

Open index.html in a modern browser for the regular vocabulary workflow. Keep
the entire project folder together; moving index.html by itself will break the
local scripts, data, and audio.

Microphone recording requires a secure browser context. For local speaking
practice, run `python -m http.server 8080` inside the project folder and visit
http://localhost:8080. HTTPS static hosting also works.

8. DEPLOYMENT

The site is a static application and can be hosted on GitHub Pages, Cloudflare
Pages, Netlify, or Vercel. The current public deployment uses GitHub Pages.

9. OPTIONAL PHONEME ASSESSMENT

The default speaking feedback uses browser speech recognition to identify missing
words and is not presented as phoneme-level scoring. To add phoneme-level
feedback, run an OpenPronounce-compatible POST /pronunciation endpoint and set
its URL in speaking-config.js:

window.SPEAKING_LAB = {
  analyzerEndpoint: "http://localhost:8000/pronunciation"
};

The endpoint must allow CORS from the website origin. If it is unavailable, the
site falls back to recording, replay and word-gap feedback without blocking the
speaking workflow.

# LEX 07.5

IELTS 全科本地优先学习工作台。

网站：https://taxil0o.github.io/ielts-vocab-studio/

## v1.3 功能

- 4,810 词 IELTS 词库、每日 100 词、三天复习与同义替换。
- 独立公开资源库：官方免费外链、CC BY 教材、公共领域文本与音频、开放数据和多语例句。
  支持技能/许可证筛选、收藏、清单导入导出，共 12 条初始资源。
- 精听实验室：本地音频和 SRT/VTT/TXT、逐句听写、A–D 错因、48 小时复测。
- 阅读实验室：20 分钟 13 题、证据位置、三类错因、同义替换表。
- 写作实验室：Task 1 六类图表、Task 2、20/40 分钟、四项自评、两版修改。
- 口语精练与三套可切换的完整 Part 1/2/3 模考。
- 全真模考中心：听力 30 + 阅读 60 + 写作 60 + 口语 15 分钟。
- 统一 IndexedDB 训练记录、周训练趋势、六个计划检验点和冲刺模式。
- Anime.js、AutoAnimate、Morphdom 和 Web Vitals 动效/性能层。
- 词库与同义替换按需加载，首屏不再下载约 2.3MB 的未使用数据。
- 设置页支持丰富动效、减弱动态效果和关闭动效三档。
- 手机和桌面响应式布局，JSON 导入导出。

## 数据与版权

- 学习记录保存在浏览器本地，不上传账号数据。
- 精听音频和口语录音只在当前标签页读取，刷新后需重新选择。
- 网站只附带原创示例材料，不包含剑桥真题、商业音频或来源不明的题库。
- 模考分数、自评和自动反馈均不是官方 IELTS 成绩。

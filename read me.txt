LEX 07.5 / IELTS VOCABULARY STUDIO
雅思场景词汇学习网站

一、项目简介

这是一个面向雅思词汇学习的本地优先网站。它把“每天学习 100 个词条、前四天学习、
后三天复习、完成一个场景词包后再进入下一个词包”的学习规则做成了可交互页面。

网站提供两类词表：

1. 第 1 轮场景计划：400 个生活日常词条，分为 4 个学习日。
2. 雅思词库：约 4,810 个带 IELTS 标签的词条，按使用场景分成词包，可自行加入计划。

二、主要功能

- 每日 100 词学习台、进度环和学习步骤清单
- 首页学习地图统一汇总词汇、同义替换、场景短文与口语练习进度
- 每日闭环步骤可直接进入对应板块，完成状态仍可独立勾选
- 单词卡片翻转、固定英式发音、掌握度和完成状态记录
- 每个词条提供中文释义和英文释义，英文释义在词卡、词表和词库中同步展示
- 同义替换记忆区：题目表达、原文替换、英文释义、原句和改写句
- 同义替换状态和进度独立保存，可按类别、搜索和掌握状态筛选
- 按单词、中文、词包和加入状态筛选
- 三天复习：听音识别、拼写、写作输出
- 词汇按连续复习结果安排下次到期日，复习题优先抽取到期和薄弱词
- 听音识别在作答前隐藏英文答案，避免“看词选义”的无效练习
- 4 篇场景短文、重点词高亮、理解题和 8 空挖空
- 场景短文支持单独标记完成，并计入首页学习地图
- 口语精练：4 篇 25–30 秒微型对话、连读块拆解、三档字幕辅助
- 麦克风录音、即时回听、浏览器漏词匹配、录音结果本地保存
- 口语问题词可一键加入原有“三天复习”词池
- 自选场景词包，自动去重后加入个人计划
- 自选词自动按每 100 词生成 Day 1、Day 2……训练日
- 主页与侧边栏可切换“第 1 轮”和“自选计划”，两套进度独立保存
- 学习进度保存在浏览器 localStorage
- 进度 JSON 导入/导出、词表 CSV 导出
- 桌面与手机响应式布局

三、词库分类

- 高频核心
- 生活日常
- 社交人际
- 工作职业
- 学习教育
- 健康医疗
- 旅行交通
- 城市环境
- 科技媒体
- 消费经济
- 社会议题
- 学术表达
- 通用词汇

分类依据词条的中文释义、英文释义和主题关键词自动整理。词义跨多个主题时，
会优先进入匹配度最高的词包；用户仍可通过全库搜索找到它。

四、固定发音

计划词与雅思词库优先播放随网站托管的 MP3，固定音色为：

en-GB-RyanNeural

这样电脑、手机和其他访问者听到的是同一套英式发音，而不是各自系统的不同语音。
如果某个音频文件缺失，网站才回退到浏览器语音。

五、数据来源与许可

雅思词库使用 ECDICT 的公开数据：

项目：https://github.com/skywind3000/ECDICT
许可：MIT License

网站中的第 1 轮场景词表、分类规则、学习流程、短文和界面为本项目自行整理。
ECDICT 用于提供英文单词、音标、中文释义、词性和 IELTS 标签。

同义替换词族使用 Open English WordNet 2025：

项目：https://github.com/globalwordnet/english-wordnet
许可：CC BY 4.0；底层数据同时包含 Princeton WordNet 的许可声明。

考试高频改写、例句和学习流程为本项目整理。

六、隐私与数据

- 网站没有登录系统，也不上传个人学习记录。
- 每个人的完成状态、掌握度和复习分数只存在自己的浏览器中。
- 跟读录音不会写入 localStorage，也不会主动上传到本站服务器。
- 如果浏览器提供语音听写，识别过程可能由浏览器或系统服务商处理音频；网站会明确标注这一点。
- 若配置了可选音素评测服务，录音会发送到该服务地址，具体隐私取决于部署者。
- 口语练习的时长、漏词和分数摘要会与学习进度一起保存在本机。
- 清除浏览器站点数据会清空该设备的进度。
- 建议每周使用网站的“导出进度”保存一份 JSON 备份。

七、本地运行

普通学习功能可直接双击 index.html 使用。
请保持整个文件夹完整，不要只移动 index.html。

麦克风录音需要浏览器安全上下文。建议在网站目录运行：

python -m http.server 8080

然后访问 http://localhost:8080。公开部署到 GitHub Pages 等 HTTPS 地址后，
录音功能也能直接使用。

八、部署

网站是纯静态站点，可部署到 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。
本项目当前准备发布到 GitHub Pages。

九、可选：接入音素级评测

网站默认使用浏览器听写做“是否漏词”的轻量反馈，不会把文字识别误称为音素评分。
如需细到音素级，可自行运行 OpenPronounce 兼容的 POST /pronunciation 服务，
再编辑 speaking-config.js：

window.SPEAKING_LAB = {
  analyzerEndpoint: "http://localhost:8000/pronunciation"
};

评测服务需要允许当前网站来源的 CORS 请求。未配置或连接失败时，网站会自动
保留录音、回听和漏词匹配功能，不会阻塞口语练习。
